# Agent Board ECS 安全组清单

部署前在阿里云 ECS 安全组和宝塔防火墙逐项核对。此文件是检查清单，不包含任何账号、密钥或真实 IP。

## 允许入站

- `443/tcp`：公网开放，用于 Admin/API HTTPS；仅绑定已配置域名和有效证书。
- `80/tcp`：公网开放，仅用于跳转 HTTPS；不承载业务接口。
- SSH 端口：只允许管理员可信出口 IP，禁止长期 `0.0.0.0/0`。
- 宝塔面板端口：只允许管理员可信出口 IP，禁止交给 Agent Board 用户。

## 禁止公网入站

- `5432/tcp` PostgreSQL。
- `3100/tcp` Admin 容器端口。
- `3200/tcp` API 容器端口。

Compose 已将这三个服务端口绑定到 `127.0.0.1`；安全组仍需确认没有其他规则、IPv6 规则或旧容器绕过该约束。

## 出站与主机检查

- 允许 DNS、NTP 和必要的 HTTPS 出站；按业务需要限制其他出站。
- PostgreSQL 仅加入 Compose 私有网络，API 是唯一业务访问方。
- 开启系统补丁、磁盘容量、容器重启和证书到期监控。
- 生产日志不得包含密码、Token、兑换码明文、客户端私钥或服务器 License Signing Private Key。
- 备份目录使用最小权限；异地备份传输和存储均加密。
